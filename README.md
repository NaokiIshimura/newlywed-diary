# 新婚日記

結婚から定年までを「買う・買わない／高い・普通・安い」の選択だけで駆け抜ける人生シミュレーションです。企画と仕様は [新婚日記 企画・設計書.md](./新婚日記%20企画・設計書.md) にあります。

## いまの状態（フェーズ3：演出とリザルト）

結婚から定年まで1周通して遊べます。設計書の12イベントとランダムイベントがすべて入っています。

- 開始設定（主人公とパートナーの性別、結婚時の年齢、貯金、ふたりの年収、働き方。ランダム・全部おまかせ）
- ライフイベント：結婚式、新婚旅行、子どもを望むか（3人まで）、働き方の見直し、車、保育、小学校、中学校、高校、大学（4年／6年）、マイホーム、家族旅行・記念日
- ランダムイベント（毎年30%）：昇進、転職の誘い、病気・ケガ、親の介護、ボーナスカット、臨時収入
- 所有物のリスク：車の故障、家の修繕、中古住宅の大規模リフォーム
- 子どもの独立：教育にかけた度合いに応じて仕送りがあり、奨学金を借りた場合は肩代わりすることがある
- 演出：イベントごとのイラスト（インライン SVG）、選択に応じた日記の文、年末の収支の表示（設定で消せる）
- リザルト：ランクとひとこと評価、称号、純資産、同じ条件の「全部普通」との差額、生涯支出の内訳、実績、人生年表、シェア用の画像カード（保存・共有・X への投稿）
- エンディング図鑑（エンディング・称号・実績の収集状況）と設定画面
- 途中保存と「続きから」

まだ入れていないもの（フェーズ4）：多言語（5言語の UI）、国プロファイルの切り替え。

## バランス

`npm run simulate` の結果（28歳・貯金200万・ふたりとも中央値の年収・共働きから、方針ごとに1,000回）です。

| 方針 | 純資産の中央値 | 破綻 |
| --- | --- | --- |
| 全部普通 | 約2,430万円（B） | 8% |
| 全部安い | 約2,180万円 | 18% |
| 全部高い | 破綻 | 61% |
| ランダム | 約1,530万円 | 35% |
| 要所だけ高い（フルタイムを続け、ほかは普通） | 約3,230万円（A） | 3% |

方針の細かい決め方と、調整で変えた値は設計書の「自動プレイの結果」にあります。

## 遊び方（ローカル）

データを `fetch` で読むので、ファイルを直接開くのではなく、静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面（タイトル・開始設定・メイン・イベント・リザルト・エンディング図鑑・設定） |
| `css/style.css` | 見た目（スマホ縦持ち優先、ダークモード対応） |
| `js/engine.js` | ゲームロジック。DOM に依存しないので、テストと自動プレイからも使う |
| `js/app.js` | 画面の操作 |
| `js/illust.js` | イベントのイラスト（SVG） |
| `js/share.js` | シェア用の画像カードを canvas に描く |
| `js/storage.js` | localStorage（途中保存・図鑑と実績の記録・設定） |
| `data/jp.json` | 日本プロファイル。イベントの金額・確率・日記の文・称号・実績はすべてここで定義する |
| `tools/simulate.mjs` | 方針（全部高い／普通／安い／ランダム）ごとの自動プレイ |
| `test/engine.test.mjs` | ゲームロジックのテスト |

## テストと自動プレイ

```bash
npm test                  # node --test
npm run simulate -- 1000  # 方針ごとに1,000回自動プレイして、純資産の分布を出す
```

乱数はシード付きで、同じシードなら同じ人生になります。
