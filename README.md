# 新婚日記

結婚から定年までを「買う・買わない／高い・普通・安い」の選択だけで駆け抜ける人生シミュレーションです。企画と仕様は [新婚日記 企画・設計書.md](./新婚日記%20企画・設計書.md) にあります。

## いまの状態（フェーズ1：プロトタイプ）

テキストだけで、結婚から定年まで1周通して遊べます。

- 開始設定（主人公とパートナーの性別、結婚時の年齢、貯金、ふたりの年収、働き方。ランダム・全部おまかせ）
- 結婚式（やる／やらない → 高い／普通／安い）
- 子ども（望む／今は望まない／生涯持たない。望むと毎年35%で誕生、プロトタイプでは1人まで）
- 車（購入と買い替え、中古車の故障、今は買わない／生涯持たない）
- 家（頭金20%＋35年ローン、固定資産税・修繕積立金・管理費、家の修繕、今は買わない／生涯賃貸）
- 年末の収支（年収の中央値カーブ、生活費、子ども生活費、家賃、ローン、車、カードローンの利息）
- 定年（65歳）で純資産からランクを表示。−1,000万円を下回ると家計破綻エンド
- 途中保存（localStorage）と「続きから」

まだ入れていないもの（フェーズ2以降）：新婚旅行、働き方の見直し、保育・進学、家族旅行、ランダムイベント、2人目以降の子ども、称号・実績、イラスト、シェア、多言語。

バランス調整はフェーズ2で行います。いまは教育費やランダムイベントがないので、「全部普通」で純資産が約9,000万円（S）になり、目標の約2,000万円よりかなり高く出ます。

## 遊び方（ローカル）

データを `fetch` で読むので、ファイルを直接開くのではなく、静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面（タイトル・開始設定・メイン・イベント・リザルト） |
| `css/style.css` | 見た目（スマホ縦持ち優先、ダークモード対応） |
| `js/engine.js` | ゲームロジック。DOM に依存しないので、テストと自動プレイからも使う |
| `js/app.js` | 画面の操作 |
| `data/jp.json` | 日本プロファイル。イベントの金額・確率・日記の文はすべてここで定義する |
| `tools/simulate.mjs` | 方針（全部高い／普通／安い／ランダム）ごとの自動プレイ |
| `test/engine.test.mjs` | ゲームロジックのテスト |

## テストと自動プレイ

```bash
npm test                  # node --test
npm run simulate -- 1000  # 方針ごとに1,000回自動プレイして、純資産の分布を出す
```

乱数はシード付きで、同じシードなら同じ人生になります。
