# 新婚日記

結婚から定年までを「買う・買わない／高い・普通・安い」の選択だけで駆け抜ける人生シミュレーションです。企画と仕様は [新婚日記 企画・設計書.md](./新婚日記%20企画・設計書.md) にあります。

## いまの状態（フェーズ4：ローカライズ）

結婚から定年まで1周通して遊べます。設計書の12イベントとランダムイベントがすべて入っています。

- 開始設定（主人公とパートナーの性別、結婚時の年齢、貯金、ふたりの年収、働き方。ランダム・全部おまかせ）
- ライフイベント：結婚式、新婚旅行、子どもを望むか（3人まで）、働き方の見直し、車、保育、小学校、中学校、高校、大学（4年／6年）、マイホーム、家族旅行・記念日
- ランダムイベント（毎年30%）：昇進、転職の誘い、病気・ケガ、親の介護、ボーナスカット、臨時収入
- 所有物のリスク：車の故障、家の修繕、中古住宅の大規模リフォーム
- 子どもの独立：教育にかけた度合いに応じて仕送りがあり、奨学金を借りた場合は肩代わりすることがある
- 演出：イベントごとのイラスト（インライン SVG）、選択に応じた日記の文、年末の収支の表示（設定で消せる）
- ドット絵の場面：メイン画面の上とリザルトに、本人・パートナー・住まい・車をドット絵で出す（Issue #24）
- リザルト：ランクとひとこと評価、称号、純資産、同じ条件の「全部普通」との差額、生涯支出の内訳、実績、人生年表、シェア用の画像カード（保存・共有・X への投稿）
- エンディング図鑑（エンディング・称号・実績の収集状況）と設定画面
- 途中保存と「続きから」

- 5言語（日本語・English・繁體中文・Español・한국어）
- 舞台の国（国プロファイル）：日本・米国・シンガポール・フィリピン・カナダ・オーストラリア・メキシコ・台湾・韓国。英語は米国・シンガポール・フィリピン・カナダ・オーストラリアから開始設定で選べ（最初は米国）、スペイン語はメキシコ、繁體中文は台湾、한국어は韓国、日本語は日本（Issue #14）

設計書のフェーズ1〜4はすべて終わり、いまは国プロファイルを増やしています。

## 一人暮らし日記からの引き継ぎ

前日譚の [一人暮らし日記](https://github.com/NaokiIshimura/solo-living-diary) の結果から、`/<言語>/?from=solo&d=<base64url の JSON>` で来たときは、引き継いだ開始設定から始めます（形式は一人暮らし日記の設計書の「新婚日記への引き継ぎ」）。

- 引き継ぎデータの版2は国（`country`）を持ち、金額はその国のプロファイルの単位のまま。版1（国なし）は日本として読む。新婚日記はその国で始め（ページの言語の国でなくてもよい。引き継ぐあいだは国を変えられない）、まだその国のプロファイルがなければ引き継がない

- 主人公の性別・結婚時の年齢・年収は一人暮らし日記のまま（変えられない）。パートナーの性別・年収・働き方はふつうどおり選ぶ
- 貯金は「引き継いだ貯金＋パートナーの貯金」で、引き継ぎのときだけ上限（日本は1,000万円）がない。マイナスならそのまま持ち込む
- 車は値段・売却額・年数・維持費・故障率をそのまま使い、表示の名前は国産新車か中古車に読み替える。買い替えの時期は買った年齢から数える
- 知らない版や壊れたデータ、範囲の外の値なら、黙って無視してタイトル画面を出す。「引き継がずに始める」も選べる
- リザルトと人生年表に、一人暮らし日記から来たことを出す
- タイトル画面から一人暮らし日記へリンクする

国の読み取りは `js/engine.js` の `handoffCountry`、読み込みは `parseHandoff`、開始設定は `handoffSettings`。

## 多言語と国プロファイル

| 言語 | URL | 最初の国 | 金額の表示（日本） | 金額の表示（米国） |
| --- | --- | --- | --- | --- |
| 日本語 | `/ja/` | 日本 | 350万円 | $5.7万 |
| English | `/en/` | 米国 | ¥3.5M | $57K |
| 繁體中文 | `/zh-tw/` | 台湾 | ¥350萬 | US$5.7萬 |
| Español | `/es/` | メキシコ | JPY 3.5 M | USD 57 K |
| 한국어 | `/ko/` | 韓国 | JP¥350만 | US$5.7만 |

nacn.app のほかのサイトと同じく、言語ごとのフォルダに分けています（claude-skills の `localize-static-app` スキル）。各言語のページは、タイトル・説明・画面の文・hreflang・canonical・OGP（`<言語>/og.png`）・構造化データを最初からその言語で書き出すので、検索エンジンと SNS にも言語ごとに出ます。

- ルート（`/`）は言語を選ぶページです。以前の URL の `?lang=`、前に選んだ言語（`localStorage` の `lang`。nacn.app の全サイトで共通）、ブラウザの言語の順に、その言語のページへ自動で移ります。どれにも当てはまらなければ、ここで選んでもらいます。スペインのブラウザ（`es-ES`）は、スペイン語版が中南米向けなので自動では移しません。`/?choose` で開くと移らずに選び直せます
- 各ページのタイトル画面の下の言語のリンクと、設定画面の言語の選択欄は、その言語のページへ移ります（選んだ言語を `lang` に覚える）。途中保存は言語に依存しないので、切り替えても続きから遊べます
- ブラウザの言語が別の対応言語なら、画面の上に1行で案内します（`src/parts/suggest.html`。閉じたら次から出さない）
- 文は2種類に分けています
  - `i18n/<言語>.json`：画面の文と、日記の共通の文（キーは `h.*`）
  - `data/profiles/<国>/<言語>.json`：国プロファイルの文（イベントの選択肢・日記・ランク・称号・実績・働き方）
- 数値は `data/profiles/<国>.json` にあり、言語には依存しません。ゲームのロジック（`js/engine.js`）は文を持たず、日記にはキーと差し込む値だけを残します
- 文の中の `{name}` に値を差し込みます。`{name:money}` のように書式を付けると、金額（`money`）・数（`num`）・符号付き（`signed`・`signedMoney`）・主人公かパートナーか（`who`）として表示します。`n` が 1 のときは、キーに `_one` を付けた文があればそちらを使います
- 翻訳のキーと差し込みが日本語版とそろっているかは `npm run check:i18n` で確かめます

### 国（国プロファイル）

国の選び方は、一人暮らし日記とそろえています（両作品のセッションで取り決め、ユーザーが一人暮らし日記の形に合わせると決めた）。

- 国の対応表は `data/countries.json` にあり、ゲーム（`js/app.js`）と `build.py` の両方が読む
  - `available`：数値と文のそろった国
  - `byLang`：言語ごとに選べる国（先頭がその言語の既定）。ja:[jp]、en:[us, sg, ph, ca, au]、zh-tw:[tw]、es:[mx]、ko:[kr]
  - `texts`：国ごとに文のある言語（先頭がその国の言語）
- 選べるのは、ページの言語の `byLang` のうち `available` にある国だけ。ひとつもなければ日本
- 最初の国は、ページの言語の既定の国だけで決める（ハッシュ・前に選んだ国・ブラウザの地域は見ない）。選べる国が2つ以上ある言語だけ、開始設定に「国・地域」の選択欄を出し、国を変えるとその国のプロファイルで開始設定をやり直す
- 状態と途中保存に国（`country`）を持たせ、続きはその国で遊ぶ（国を分ける前の保存は日本）。その国の文がページの言語になければ、`texts` の先頭の言語の文を使う。最高の純資産は通貨がちがうので国ごとに記録する
- 一人暮らし日記からの引き継ぎは、引き継いだ国で始める。その国がページの言語の国でなくても、`available` にあれば始める。国の選択欄は出さない
- 国の数値（`data/profiles/<国>.json`）に、開始設定の範囲と初期値（`startAge`・`defaultAge`・`startSavings`）、金額の刻み（`moneyStep`）、入力欄の1が金額の何単位か（`inputScale`。日本は万円のまま1、米国は $1,000 で入れるので10）、年収の上限（`maxIncome`）、引き継ぎの範囲（`handoffLimits`）、通貨（`currency`）と金額の単位（`moneyUnit`。日本は1万円、米国・シンガポール・カナダ・オーストラリアは100ドル、フィリピンとメキシコは1,000ペソ、台湾は1,000台湾ドル（入力は萬元）、韓国は1만원で、一人暮らし日記と同じ）、言語ごとの通貨の記号（`currencySymbol`。シンガポールドルを「SGD 54K」ではなく「S$54K」、ペソを「₱340K」、カナダドルを「C$59K」、オーストラリアドルを「A$85K」、メキシコペソを「MX$200 k」、台湾ドルを「NT$52萬」、ウォンを「₩3700만」と書く）がある。家の頭金の割合は選択肢ごとに変えられる（`downPaymentRate`。シンガポールは HDB 5%・マンション 25%）
- 国の文（`data/profiles/<国>/<言語>.json`）の `local` に、その国だけの言い方（舞台の説明・入力の単位・ご祝儀・子どもの手当・大学6年の例）がある
- `build.py` は、各言語のページをその言語の既定の国の文で書き出す（`default_country`）

国を足すときは、`data/profiles/<国>.json`（数値。出典は設計書の「国プロファイル」）と、その国を選べる言語の `data/profiles/<国>/<言語>.json`（文）を作り、`data/countries.json` の `available` と `texts`、全言語の `i18n/<言語>.json` の `countries` に足して、`npm run simulate -- 1000 <国>` でバランスを合わせます。一人暮らし日記にも同じ国を同時に公開します（引き継いだ金額の単位をそろえるため）。米国の文は5言語ぶん書いてあります（引き継ぎや途中保存で、英語以外のページから米国を遊ぶときのため）。

言語を足すときは、`js/i18n.js` の `LANGS` と `build.py` の `LANGS`・`SPEAKER_ORDER`・`BROWSER_MATCH` に足し、2種類の文のファイルを日本語版から訳して、`i18n/<言語>.json` の `site`（`<html lang>`・hreflang・OGP のロケール・言語名・案内の文・同意のバナーの文）も書きます。

## 遊び方（ローカル）

データを `fetch` で読むので、ファイルを直接開くのではなく、静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000/ja/ などを開く（http://localhost:8000/ は言語を選ぶページ）
```

## ページの書き出し

各言語のページは `build.py` で書き出します（Python 3 の標準ライブラリだけ）。Cloudflare Pages ではビルドしないので、`src/`・`i18n/`・`data/profiles/<国>/<言語>.json` を変えたら、書き出して一緒にコミットします。

```bash
python3 build.py      # <言語>/index.html・<言語>/howto.html・<言語>/privacy.html・index.html（言語を選ぶページ）・404.html・sitemap.xml を書き出す
node tools/make_og.cjs # <言語>/og.png（OGP 画像）を作る。作り直したら build.py の ASSET_VER を新しくして書き出し直す
```

| ファイル | 内容 |
| --- | --- |
| `src/game.html` | ゲームのページの枠。`{{...}}` に言語ごとの値を差し込み、`data-i18n` の要素にはその言語の文を入れて書き出す |
| `src/page.html` | 文章のページ（遊び方・プライバシーポリシー）の枠 |
| `src/pages/<言語>/howto.html`・`privacy.html` | 文章のページの本文。名前と説明は `i18n/<言語>.json` の `pages` |
| `src/root.html`・`src/404.html` | ルートの言語を選ぶページと、見つからないページ |
| `src/parts/suggest.html` | ブラウザの言語に合わせた1行の案内（nacn.app 共通） |
| `src/parts/consent-head.html`・`src/parts/consent.html` | Cookie の同意の初期値とバナー（nacn.app 共通） |

`<言語>/*.html`・ルートの `index.html`・`404.html`・`sitemap.xml` は書き出したファイルなので、直接は編集しないでください。

ゲームと文章のページの画面下には、同じサイト内メニュー（遊び方・運営者情報・お問い合わせ・プライバシーポリシー・nacn.app のほかのゲーム。文章のページでは先頭に「ゲームで遊ぶ」）を `build.py` の `site_nav()` で書き出します。運営者情報とお問い合わせは、nacn のゲームで共通の nacn.app のページ（`https://nacn.app/<言語>/about.html`）へリンクしています。遊び方とプライバシーポリシーに書いた数値や保存する情報は、ゲームのコードとデータ（`data/profiles/<国>.json`・`js/storage.js`）から取っているので、ゲームを変えたらこの2ページも直します。

### アクセス解析と Cookie の同意

- Google アナリティクス（測定ID `G-WFHQNP9CT8`）のタグを、書き出す全ページ（`src/game.html`・`src/root.html`・`src/404.html`）の head に入れています。AdSense は入れていません
- Cookie の同意のしくみ（Google Consent Mode v2 と同意のバナー）は nacn.app 共通のものです。部品は `src/parts/consent-head.html`・`src/parts/consent.html`、言語ごとの文言は `i18n/<言語>.json` の `site.consent` にあり、`build.py` の `with_consent()` が書き出すときに入れます（初期値は全ページ、バナーは言語のページだけ）。部品の元の版は claude-skills の `consent-mode` スキルにあるので、直すときはそちらを先に直して写します
- 同意を求めるのは、端末のタイムゾーンがインドネシア・タイ・ベトナムの人です。EU・英国・スイスは Google の位置判定で最初から拒否にします。選択は `.nacn.app` の Cookie `nacn_consent` に保存され、nacn.app の全サイトで共通です
- AdSense を入れていないので、バナーは「アクセスの集計のため」だけの文言にしています。AdSense を入れたら、`i18n/<言語>.json` の `site.consent.text` を広告ありの文言に戻します
- 同意のバナーの「プライバシーポリシー」は、このゲームのポリシー（`/<言語>/privacy.html`）へのリンクです。ゲームと文章のページの画面下のメニューには「Cookie の設定」も自動で足されます
- `<html lang>` はページを書き出すときに決まるので、同意の判定（言語が `id` か）にもそのまま使えます
