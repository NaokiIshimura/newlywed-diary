# 新婚日記

結婚から定年までを「買う・買わない／高い・普通・安い」の選択だけで駆け抜ける人生シミュレーションです。企画と仕様は [新婚日記 企画・設計書.md](./新婚日記%20企画・設計書.md) にあります。

## いまの状態（フェーズ4：ローカライズ）

結婚から定年まで1周通して遊べます。設計書の12イベントとランダムイベントがすべて入っています。

- 開始設定（主人公とパートナーの性別、結婚時の年齢、貯金、ふたりの年収、働き方。ランダム・全部おまかせ）
- ライフイベント：結婚式、新婚旅行、子どもを望むか（3人まで）、働き方の見直し、車、保育、小学校、中学校、高校、大学（4年／6年）、マイホーム、家族旅行・記念日
- ランダムイベント（毎年30%）：昇進、転職の誘い、病気・ケガ、親の介護、ボーナスカット、臨時収入
- 所有物のリスク：車の故障、家の修繕、中古住宅の大規模リフォーム
- 子どもの独立：教育にかけた度合いに応じて仕送りがあり、奨学金を借りた場合は肩代わりすることがある
- 演出：イベントごとのイラスト（インライン SVG）、選択に応じた日記の文、年末の収支の表示（設定で消せる）
- リザルト：ランクとひとこと評価、称号、純資産、同じ条件の「全部普通」との差額、生涯支出の内訳、実績、人生年表、シェア用の画像カード（保存・共有・X への投稿）
- エンディング図鑑（エンディング・称号・実績の収集状況）と設定画面
- 途中保存と「続きから」

- 5言語（日本語・English・繁體中文・Español・한국어）。舞台は日本（日本プロファイル）のまま、文と金額の表示だけを言語に合わせる

設計書のフェーズ1〜4はすべて終わりました。日本以外の国プロファイルはまだありません（仕組みだけ用意しています）。

## 多言語と国プロファイル

| 言語 | URL | 金額の表示 |
| --- | --- | --- |
| 日本語 | `?lang=ja` | 350万円 |
| English | `?lang=en` | ¥3.5M |
| 繁體中文 | `?lang=zh-tw` | ¥350萬 |
| Español | `?lang=es` | JPY 3.5 M |
| 한국어 | `?lang=ko` | JP¥350만 |

- 言語は `?lang=`、前に選んだ言語（設定）、ブラウザの言語の順に決めます。対応していない言語のブラウザでは英語にします。中国語のブラウザは繁體中文にします
- タイトル画面の下と設定画面で切り替えられます。途中保存は言語に依存しないので、切り替えても続きから遊べます
- 文は2種類に分けています
  - `i18n/<言語>.json`：画面の文と、日記の共通の文（キーは `h.*`）
  - `data/profiles/<国>/<言語>.json`：国プロファイルの文（イベントの選択肢・日記・ランク・称号・実績・働き方）
- 数値は `data/profiles/<国>.json` にあり、言語には依存しません。ゲームのロジック（`js/engine.js`）は文を持たず、日記にはキーと差し込む値だけを残します
- 文の中の `{name}` に値を差し込みます。`{name:money}` のように書式を付けると、金額（`money`）・数（`num`）・符号付き（`signed`・`signedMoney`）・主人公かパートナーか（`who`）として表示します。`n` が 1 のときは、キーに `_one` を付けた文があればそちらを使います
- 翻訳のキーと差し込みが日本語版とそろっているかは `npm run check:i18n` で確かめます

言語を足すときは、`js/i18n.js` の `LANGS` に足して、2種類の文のファイルを日本語版から訳します。国を足すときは、`data/profiles/<国>.json`（数値）と `data/profiles/<国>/<言語>.json`（文）を作り、`js/app.js` の `PROFILE` を切り替えます（国を選ぶ画面はまだありません）。

## バランス

`npm run simulate` の結果（28歳・貯金200万・ふたりとも中央値の年収・共働きから、方針ごとに1,000回）です。

| 方針 | 純資産の中央値 | 破綻 |
| --- | --- | --- |
| 全部普通 | 約2,430万円（B） | 8% |
| 全部安い | 約2,180万円 | 18% |
| 全部高い | 破綻 | 61% |
| ランダム | 約1,530万円 | 35% |
| 要所だけ高い（フルタイムを続け、ほかは普通） | 約3,230万円（A） | 3% |

方針の細かい決め方と、調整で変えた値は設計書の「自動プレイの結果」にあります。

## 遊び方（ローカル）

データを `fetch` で読むので、ファイルを直接開くのではなく、静的サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面（タイトル・開始設定・メイン・イベント・リザルト・エンディング図鑑・設定） |
| `css/style.css` | 見た目（スマホ縦持ち優先、ダークモード対応） |
| `js/engine.js` | ゲームロジック。DOM に依存しないので、テストと自動プレイからも使う |
| `js/app.js` | 画面の操作 |
| `js/illust.js` | イベントのイラスト（SVG） |
| `js/share.js` | シェア用の画像カードを canvas に描く |
| `js/storage.js` | localStorage（途中保存・図鑑と実績の記録・設定） |
| `js/i18n.js` | 言語の切り替えと、文への差し込み・金額の書式 |
| `i18n/<言語>.json` | 画面の文と日記の共通の文 |
| `data/profiles/jp.json` | 日本プロファイルの数値（イベントの金額・確率・年収の表など）と、称号・実績の並び |
| `data/profiles/jp/<言語>.json` | 日本プロファイルの文（イベントの選択肢・日記・ランク・称号・実績） |
| `tools/simulate.mjs` | 方針（全部高い／普通／安い／ランダム／要所だけ高い）ごとの自動プレイ |
| `tools/check-i18n.mjs` | 翻訳ファイルのキーと差し込みが日本語版とそろっているかの確認 |
| `test/engine.test.mjs` | ゲームロジックのテスト |

## テストと自動プレイ

```bash
npm test                  # node --test
npm run simulate -- 1000  # 方針ごとに1,000回自動プレイして、純資産の分布を出す
npm run check:i18n        # 翻訳ファイルのキーと差し込みを確かめる
```

乱数はシード付きで、同じシードなら同じ人生になります。
